## 1. これは何か

**ドコモショップの店頭で、お客様に料金の見積もりを出すためのiPad/PC用アプリです。**

店員が接客しながら上から順に入力すると、月額・初期費用・実質負担額が自動で計算され、
そのままA4 2枚の見積書として印刷できます。お客様にお渡しする「引き継ぎシート」も出ます。

阪南店で毎日の接客に使っているものを、他店にも売れる形に作り直しました。

### 触れるURL

| | URL | 用途 |
|---|---|---|
| 社内版 | https://hisapiyp622-alt.github.io/docomo-quote/ | 阪南店の日常業務用。**ログイン不要**ですぐ開けます |
| 製品版 | https://hisapiyp622-alt.github.io/docomo-quote/keitai-app/ | 代理店に売るもの。店舗IDとパスワードが要ります |

**まず社内版を開いて、見積もりを1本作ってみてください。**
ログイン不要で、上から順に入力するだけです。何ができるアプリかは触れば5分で分かります。
阪南店が実際に使っている料金マスタがそのまま入っているので、実物どおりの動きが見られます。

### 製品版のログイン

小川さん専用のアカウントを用意しています。**このアカウントがそのまま営業用のデモ環境**です。
料金マスタを自由に書き換えても、阪南店・常盤東店には影響しません。

| | |
|---|---|
| 店舗ID | `ogawa01` |
| パスワード | 安藤さんから別途お伝えします（この文書には書きません） |

ログインしたあと、担当者コードの画面で「マスタ設定を開く」を押すと、
料金・オプション・店舗名などをすべて編集できます。**店舗名を見込み先の名前にしておくと、
見積書にその店舗名が入るので、そのままデモに使えます。**

社内版と製品版は**中身が同じ**です。違いはログインの仕組みだけなので、
機能の説明は社内版で覚えて、お客様の前では製品版を出す、という使い分けで問題ありません。

## 2. いまできること（売り文句になる部分）

- **料金プラン・割引・オプションを選ぶだけで、月額と初期費用が自動計算される**
  みんなドコモ割、光/home 5Gセット割、dカードお支払割、長期利用割、U22割などに対応
- **端末代金** — 分割回数、いつでもカエドキプログラム、頭金、クーポン値引き・キャンペーン値引き
- **実質額の案内** — ポイ活プランの還元、dカード還元、爆アゲ セレクションのポイントを自動計算して差し引ける
- **見積書がA4 2枚に収まる** — 店舗名・担当者名・電話番号が自動で入る
- **引き継ぎシート** — お客様にお渡しする、手続き内容のまとめ
- **見積もりの保存** — 名前を付けて保存し、あとから開き直せる（担当者ごとに最大50件）
- **テンプレート** — よく出す構成を担当者ごとに登録
- **料金マスタは店舗が自由に編集できる** — 自店の独自商材・独自価格を登録できる
- **料金マスタの履歴** — 料金改定の前の内容にいつでも戻せる。誰が何を変えたかも残る
- **料金改定の配信** — ドコモの料金が変わったら新しい料金表が届く。変わる内容を確認してから適用でき、店舗独自の設定はそのまま残る
- **iPad・PC・スマホの間で自動同期** — 同じ担当者コードで開けば、どの端末でも続きから
- **オフラインでも動く**（一度開いておけば圏外でも使える）
- **お客様名は端末の中だけ**に保存し、クラウドには送らない

## 3. 売るときに言ってはいけないこと

ここは間違えると後で困るので、**そのまま覚えてください。**

| ❌ 言ってはいけない | ⭕ 正しい説明 |
|---|---|
| 「ドコモ公式のツールです」 | **NTTドコモとは無関係の、当方が独自に開発したツールです。** 資本関係も提携関係もありません |
| 「この金額で契約できます」 | あくまで**ご説明を補助するための概算**です。最終的な金額と適用条件は正規の販売システムで確認が必要です |
| 「料金改定は勝手に反映されます」 | **料金表はこちらから配信します。**店舗のアプリに「料金表の更新があります」と出るので、内容を確認して適用していただく形です（お店で登録した独自サービスや価格はそのまま残ります） |
| 「爆アゲのポイントは必ずもらえます」 | 進呈条件はドコモ側の都合で変わります。月2回、こちらで公式情報を確認して更新しています |

見積書の下端にも「本書は当店が作成したご案内であり、NTTドコモが発行するものではありません」と
必ず印字されるようになっています。**この一文は消せません**（消してはいけません）。

## 4. 話せること・まだ話せないこと

**話せること**（2026-07-29 に決定）

| 項目 | 内容 |
|---|---|
| 契約単位 | **店舗単位**（1契約＝同一住所の1店舗。端末数・担当者数は無制限） |
| 支払方法 | **銀行振込**（振込手数料はお客様負担） |
| サポート | **10:00〜18:00**（土日祝・年末年始を除く）／応答の目安は翌営業日中 |
| 解約 | 1か月前までのご連絡。解約後30日でクラウド上のデータを削除 |
| 提供元 | **株式会社cracon**（**仮称**。登記前のため、この名前で契約書は交わせません） |

**まだ話せないこと**

1. **価格** — 初期費用・利用料金とも未定。**月額制か買い切りかも決まっていません。**
   **金額を口にしないでください。** 一度出した数字は下げられません
2. 支払期日・締め日（価格の形が決まってから）
3. サポート窓口のメールアドレス
4. 管轄裁判所・制定日

利用規約・使用許諾条件は、決まった分まで埋めてあります。
**残りの `〔　〕` が埋まるまで、代理店にお渡しできません。**

このほか、**製品名も確定していません**（画面によって「ドコモ料金見積もり」と「ケータイ見積もり」が混在）。
非公式ツールの名前に「ドコモ」を入れておくのは良くないため、変える前提です。

## 5. 小川さんにお願いしたいこと（優先順）

### ① まず社内版を触る（30分）

https://hisapiyp622-alt.github.io/docomo-quote/

見積もりを1本作って、見積書を印刷プレビューまで出してみてください。
**「これは売れる／ここが足りない」の一次判断を先にください。** 作り込む前に聞きたいです。

### ② 見込み先を10〜20件リストにする

関西圏の2次店を狙う前提です。次の情報があると、価格設計がしやすくなります。

- 店舗名／運営会社／店舗数
- いま見積もりを何で作っているか（正規システムの画面、Excel、手書き、など）
- 端末は何を使っているか（iPad があるか）

### ③ ヒアリングで「いくらなら」の感触を取ってくる ← いちばん重要

**これが最優先です。**

価格が決まらないせいで、規約も契約書も課金の仕組みも全部止まっています。
そして価格は、こちらで決めるより**相手に聞いたほうが早い**です。

正式な提示はまだできないので、こういう聞き方をしてください。

> 「まだ正式な価格は決めていないのですが、こういうツールがあったら、
> 1店舗あたり月いくらくらいなら使いますか？ 初期費用はどのくらいまでなら許容できますか？」

聞いてきてほしいのは3つだけです。

- **月額の感覚**（3,000円？ 5,000円？ 10,000円？ どのあたりで「高い」と言われるか）
- **初期費用の許容範囲**（設定・マスタ投入・説明を含めて）
- **決裁の単位**（店長判断で決まるのか、本部決裁か。本部決裁なら法人単位の契約が必要）

3〜5社から聞ければ、価格を決められます。**そこから先は一気に進みます。**

### ④ カード払いか請求書払いかを確認する

法人相手だとカード払いを嫌う会社が多いので、これも聞いてきてください。
決済の仕組みを作る前に知っておきたい情報です。

### ⑤ デモを1回通しで練習しておく

`ogawa01` で製品版にログインし、**お客様役を相手に見積もりを1本作るところまで**通してみてください。
本番で詰まりやすいのは、料金マスタに無い機種・オプションを聞かれたときです。
その場でマスタ設定から追加できるので、**追加のしかたも一度やっておいてください。**

足りないもの・分かりにくいところが出たら、そのまま安藤さんに投げてください。直します。
