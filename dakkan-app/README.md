# 他社比較（ネット回線）— 奪還ツール

店頭で「いまお使いの他社のネット回線から、ドコモ光・home 5G に乗り換えたらどうなるか」を、
その場で数字にして **A4 1枚** にしてお渡しするためのアプリです。

- 指示書: `_internal/DAKKAN_SPEC.md`
- サーバー処理なし。HTML・CSS・素のJavaScriptだけで動きます（ビルド不要）

## 画面

| タブ | 中身 |
|---|---|
| いまのご契約 | ①他社のご契約（請求額・違約金・残債など）②乗り換えに掛かるもの ④比べる |
| ドコモにした場合 | ドコモ光・home 5G の見積もり（`ienaka.js`＝ケータイ製品版と同じ入力画面） |
| 別紙 | お客様にお渡しする1枚（印刷／PDF保存） |
| 設定 | 店舗名・お客様名・担当者・**他社の料金データ**・アカウント |

## ファイル

| ファイル | 役割 |
|---|---|
| `app.js` | 入れ物。ログイン・保存・同期・担当者・マスタ設定・別紙の体裁 |
| `dakkan.js` | ①②④と別紙の中身。`window.KQ_DAKKAN` を公開。**idは全て `dk` 接頭辞** |
| `ienaka.js` | ドコモ光・home 5G の入力と計算。**`keitai-app/ienaka.js` のコピー** |
| `data.js` | 他社回線の料金・違約金・連絡先。**マスタ設定から編集できる** |

**`ienaka.js` の正は `keitai-app/` 側です。** 直したいことが出たら keitai-app を直してから
コピーし直してください（`CLAUDE.md` の「修正の反映先」と同じ考え方）。

## 数字の決まりごと

- 「◯か月で追いつきます」は **(乗り換え費用) ÷ (月々の差額) を切り上げ**
- **差額が0以下のときは出しません**
- **空欄の費用項目は「要確認」とし、合計に入れません。**
  要確認が1つでも残っているあいだは「◯か月で追いつく」を出しません
- 更新月「更新月」→違約金0円扱い／「不明」→違約金は要確認扱い
- ドコモ光セット割（ドコモのスマホ側が下がる分）は**この別紙に含めません**（スマホの見積書で案内）
- ドコモ側の月額・初期費用は `KQ_IENAKA.calc()` から取っています。**このアプリはドコモ光の料金を持ちません**

## 他社の料金データ（`data.js`）

- **一次情報（各社の公式サイト）で確認できた値だけ**が入っています
- 公式が「マイページでご確認ください」としているもの（J:COM・SoftBank Air など）は
  **空欄のまま**です。空欄は「要確認」として扱われ、費用の合計に入りません
- 出典URLと確認日は `data.js` のコメントと、設定タブの各社の「出典」に出ます
- **料金データ基準日**は画面と別紙に出ます。値を更新したら基準日も更新してください

## クラウド保存

`firebase-config.js` は**空設定で出荷**しています。空のままでも端末内保存だけで動きます。
設定すると、店舗アカウントでのログインと端末間同期が有効になります（手順は `ienaka-app/SETUP.md` と同じ）。
**お客様名はクラウドへ送信しません。**

## 保存領域

`dk-` 接頭辞（`dk-state-v1` / `dk-config-v1` / `dk-master-v1`）。
同じドメインに `kq-`（ケータイ製品版）・`dq-`（社内版）・`ienaka-app-` が同居するため、変えないでください。
