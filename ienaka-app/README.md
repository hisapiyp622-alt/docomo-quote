# イエナカ見積もり（単体アプリ）

ドコモ光・ahamo光・home 5G の店頭見積もりを作成するWebアプリ（PWA）です。
このフォルダだけで完結しており、他のファイルに依存しません。

## 主な機能

- **店舗設定・担当者**: 「設定」タブで店舗名と担当者を登録（人数制限なし）。画面上部で担当者を切り替えると、見積もりの入力内容が担当者ごとに分かれて保存されるため、同じ端末を複数人で使っても互いの作業に影響しません。店舗名・担当者名は見積書と引き継ぎシートに表示されます
- **見積もり作成**: 商材（ドコモ光1G/10G・ahamo光1G/10G・home 5G）× 申込区分（新規／転用／事業者変更）から月額・工事費を自動判定
- **オプション**: 光電話（発信者番号表示・転送でんわ・ダブルチャネル・追加番号）、テレビオプション（スカパー／NTT工事の選択）、無線LANカード、あんしんパック ホーム など。選択に応じて工事料が初期費用へ自動加算
- **工事費**: 分割24回／一括、実質0円特典（開通6か月後から24回進呈）を加味した月額推移を自動計算
- **特典**: お申込みdポイント進呈、テレビ同時申込特典、home 5G→ドコモ光 移行特典、dカード GOLD/PLATINUM 還元の月額充当、店舗独自特典（相対対応・普段は非表示）
- **実質価格**: 家族スマホの光セット割合計を入力すると、差引後の「実質お支払い目安」を表示
- **お見積書**: A4 1枚に印刷／PDF保存
- **登録スタッフ引き継ぎシート**: プロバイダ、電話番号の引き継ぎ方法、工事内容、特典などを1枚にまとめて印刷（登録日・登録担当・備考の記入欄付き）

## ファイル構成

| ファイル | 内容 |
|---|---|
| `index.html` | 画面（入力フォーム・見積書・引き継ぎシート） |
| `app.js` | 料金マスタと計算ロジック、画面描画 |
| `style.css` | 画面・印刷スタイル |
| `sw.js` | Service Worker（オフライン動作・自動更新） |
| `manifest.webmanifest` / `icon.svg` | ホーム画面へのインストール用 |

## 設置方法

静的ファイルのみで動作します。このフォルダの中身をWebサーバー（GitHub Pages、Netlify、レンタルサーバー等）へ配置するだけです。ビルド作業やサーバーサイドの処理は不要です。

- iPad・PC・スマートフォンのブラウザで動作
- 入力内容は端末内（localStorage）に保存され、外部へ送信されません
- ホーム画面に追加するとアプリのように起動できます

## 料金マスタの更新

料金・工事費・特典の初期値は `app.js` の先頭付近にまとめてあります。

- `PRODUCTS`: 商材ごとの月額・事務手数料・工事費
- `IENAKA_OPTS`: 月額オプションと工事料
- `TV_KOJI`: テレビ工事の種別と工事料・視聴登録料・現地徴収額

料金改定時はこの3か所を更新し、`APP_VERSION` と `sw.js` の `CACHE` の値を上げてください（端末側の自動更新に使われます）。
なお画面上の金額欄はすべて手入力で上書きできるため、急な変更にも見積もり単位で対応できます。
