# クラウド保存（店舗ログイン）の設定手順

この設定を行うと、次のことができるようになります。

- 店舗ごとのアカウントでログインし、**他店のデータには一切アクセスできない**状態でデータを分離
- 同じ店舗の端末どうし（iPad ⇄ PC）で、店舗名・担当者・見積もりを**自動同期**
- 解約時にアカウントを無効化すれば、その店舗だけ利用を停止できる

設定しない場合も、アプリは端末内保存のみでそのまま使えます（ログイン画面は表示されません）。

所要時間は15分程度です。作業はすべて [Firebaseコンソール](https://console.firebase.google.com/) 上で行います。

---

## 1. Firebaseプロジェクトを作成する

1. [Firebaseコンソール](https://console.firebase.google.com/) を開き「プロジェクトを追加」
2. プロジェクト名（例: `ienaka-quote`）を入力して作成
   - Google アナリティクスは不要（オフでよい）

## 2. ウェブアプリを登録して設定値を控える

1. プロジェクトのトップで、ウェブアイコン（`</>`）をクリック
2. アプリのニックネーム（例: `ienaka-app`）を入力して登録
   - 「Firebase Hosting も設定」はチェック不要
3. 表示される `firebaseConfig` の値をコピーする

## 3. 設定値をアプリに貼り付ける

`firebase-config.js` を開き、`IENAKA_FIREBASE` の各項目を手順2の値に差し替えます。

```js
var IENAKA_FIREBASE = {
  apiKey: "AIza...",
  authDomain: "ienaka-quote.firebaseapp.com",
  projectId: "ienaka-quote",
  storageBucket: "ienaka-quote.firebasestorage.app",
  messagingSenderId: "000000000000",
  appId: "1:000000000000:web:xxxxxxxxxxxx"
};
```

`projectId` が入力された時点で、クラウド保存とログイン画面が有効になります。
なおこれらの値は、ウェブアプリでは公開される前提のものです。データの保護は手順5のセキュリティルールで行います。

## 4. ログイン方法を有効にする

1. 左メニュー「構築 → Authentication」→「始める」
2. 「Sign-in method」タブ →「メール/パスワード」を選び、**有効にする**（「メールリンク」は不要）

## 5. データベースを作成し、セキュリティルールを設定する

1. 左メニュー「構築 → Firestore Database」→「データベースの作成」
2. モードは**本番環境モード**、ロケーションは `asia-northeast1`（東京）を選択
3. 作成後「ルール」タブを開き、内容を同じフォルダの **`firestore.rules`** の中身に置き換えて「公開」

このルールにより、`stores/{店舗のUID}` 配下へは**その店舗のアカウントでログインしている場合のみ**アクセスできます。他店のデータは読むことも書くこともできません。

## 6. 店舗アカウントを作る（1店舗につき1つ）

1. 「Authentication → Users」→「ユーザーを追加」
2. 店舗ごとのメールアドレスとパスワードを設定（例: `shop-oo@example.com`）
3. 作成したメールアドレスとパスワードを、その店舗へ伝える

## 7. 動作確認

1. アプリを開く → ログイン画面が表示される
2. 手順6のアカウントでログイン
3. 「設定」タブで店舗名と担当者を登録
4. 別の端末（またはブラウザのシークレットウィンドウ）で同じアカウントでログインし、
   店舗名・担当者・見積もりが同期されることを確認
5. 画面右上に「同期✓」と表示されれば正常です

---

## 運用のポイント

| やりたいこと | 操作 |
|---|---|
| 店舗を追加する | Authentication → Users でアカウントを1つ追加 |
| 解約・利用停止 | 該当ユーザーを「無効にする」または削除 |
| パスワードを変更する | Users の該当行のメニューから「パスワードを再設定」 |
| データを確認する | Firestore Database → `stores/{UID}` |

## データの扱い

- クラウドに保存されるのは、店舗名・担当者名・見積もりの入力内容です
- **お客様名は端末内にのみ保存され、クラウドへは送信されません**（個人情報を預からない設計）
- 通信できない環境でもアプリは動作し、オンラインに戻った時点で同期されます

## 費用の目安

店舗数が数十規模であれば、Firebaseの無料枠（Spark プラン）に収まる想定です。
利用が増えた場合は従量課金（Blaze プラン）へ切り替えてください。
