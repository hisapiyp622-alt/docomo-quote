# ロゴの置き場所

このフォルダに画像を置くと、タイルがロゴ表示に切り替わります。
画像が無い間は文字のまま表示されます（動作に支障はありません）。

## 使用にあたっての注意

各社・各サービスのロゴは商標です。ドコモ／ahamo／home 5G のロゴは、代理店向けの
ブランドガイドラインに沿った使い方をしてください。プロバイダ各社のロゴは、
代理店向けに配布されている素材、または各社の広報・販売担当へ申請して入手したデータをご使用ください。

このフォルダに置いた画像は GitHub Pages で公開されます。社内だけで使う場合は、
リポジトリにコミットせず、端末のローカルに置いた状態でご利用ください。
