# プロバイダロゴの置き場所

このフォルダに画像を置くと、プロバイダ選択のタイルがロゴ表示になります。
画像が無い間は、プロバイダ名がそのまま表示されます（動作に支障はありません）。

## ファイル名

| プロバイダ | ファイル名 |
|---|---|
| OCN インターネット | `ocn.svg` または `ocn.png` |
| GMOとくとくBB | `gmo.svg` または `gmo.png` |
| @nifty | `nifty.svg` または `nifty.png` |
| ANDLINE | `andline.svg` または `andline.png` |

- 推奨サイズ: 横240px前後（表示は横118px・高さ34pxに収まるよう自動縮小）
- 背景が透明のSVG／PNGが最もきれいに表示されます

## 使用にあたっての注意

各社のロゴは商標であり、利用には**提供元の許諾が必要**です。
代理店向けに配布されている素材、または各社の広報・販売担当へ申請して入手したデータをご使用ください。
許諾が得られない場合は、画像を置かずに名前表示のままご利用ください。
