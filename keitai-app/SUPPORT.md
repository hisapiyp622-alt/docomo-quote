# サポートについて

> **本書は制定前の案です。** 窓口の連絡先は、ご契約の際にお知らせします。

## 連絡先

| | |
|---|---|
| 窓口 | 〔メールアドレス〕 |
| 受付時間 | **10:00〜18:00**（土日祝・年末年始を除く） |
| 応答の目安 | 翌営業日中 |

**緊急の連絡先は設けていません。** 障害が発生した場合も、上記の受付時間内での対応となります。

## サポートする範囲

**対応します**

- 本アプリが動かない、エラーが出る、計算結果がおかしい
- ログインできない、パスワードが分からなくなった
- 端末間の同期がうまくいかない
- 使い方が分からない（`README.md` に書かれている範囲）

**対応しません**

- **料金マスタの内容の正誤** — 料金・オプション・手数料の値が正しいかどうかは、お客様側でご確認ください
- **料金改定への追従** — マスタ設定でお客様側が変更してください（下記）
- お客様の端末・ネットワーク・ブラウザ自体の不具合
- エンドユーザーとのトラブル、契約内容に関する相談
- 本アプリ以外のシステムとの連携

## 料金改定への対応

**通信事業者の料金改定に、本アプリが自動で追従することはありません。**

改定があった場合は、**お客様がマスタ設定で変更してください。** 変更前には「料金マスタの履歴」に自動で控えが残るため、間違えても戻せます。

当方が新しい標準の料金表を用意した場合は、アプリの**「料金表の更新があります」**としてお届けすることがあります。
適用するかどうかはお客様が選べます。ただし、**時期・範囲をお約束するものではありません。**
改定に間に合わない場合は、お客様がマスタ設定で変更してください。

## 不具合の連絡のしかた

次の情報があると原因を特定しやすくなります。

1. 何をしたときに起きたか（例: 「MAXを選んでカエドキを入れたら」）
2. 何が起きたか（画面のスクリーンショットがあると確実です）
3. 使っている端末とブラウザ（例: iPad / Safari）
4. アプリの版（マスタ設定の「料金マスタ」欄、または見積書の下端に出ています）

## 機能の追加要望

要望は歓迎しますが、**対応をお約束するものではありません。** 対応する場合の費用・時期は個別にご相談させてください。
