# ケータイ見積もり

ドコモの料金プラン・オプション・端末代金を、店頭でその場で見積もるためのアプリです。
インストール不要で、ブラウザを開くだけで使えます。

## できること

- **料金プランと割引の自動計算** — みんなドコモ割・光セット割・dカードお支払割・でんきセット割・長期利用割・キャンペーンを選ぶだけで月額が出ます
- **期間ごとの金額** — キャンペーンの終了や分割の完済にあわせて「〜6か月目」「31か月目以降」のように、月額の推移を自動で段階表示します
- **端末代金** — 一括／分割12〜48回／いつでもカエドキプログラムに対応。頭金を含んだ総額から分割金を計算します
- **3パターン同時比較** — A・B・Cの3案を並べて、お客様に選んでいただけます
- **見積もりの保存** — 3パターン一式に名前を付けて保存し、あとから開き直せます（担当者ごと・最大50件）
- **テンプレート** — よく使う構成を3枠まで登録して呼び出せます（**担当者ごと**）。長押しで削除できます
- **自動ログアウト** — 1時間操作がないと自動でログイン画面へ戻ります（店頭の共有端末の置き忘れ対策）
- **お客様向けの見積書** — A4で印刷・PDF保存できます
- **登録スタッフ引き継ぎシート** — 手続き内容・オプションの新規／継続／廃止・データ移行の有無などを、A4 1枚にまとめて渡せます
- **料金マスタの編集** — プラン料金・オプション・手数料は、アプリの「料金マスタ」タブから店舗側で自由に変更できます。料金改定にも自分たちで追従できます
- **タイルの並べ替え** — 見積もり画面のタイルの並びは、マスタ設定でタイルを**長押ししてドラッグ**して変えられます。よく使う商材を左上に置けます。オプションは別のカテゴリへも移せます
- **店舗ログインと担当者コード（任意）** — 店舗ID＋パスワードでログインし、店舗内は担当者コードで切り替えます。担当者ごとに見積もりが分かれて保存されます。ヘッダーの「ログアウト」でいつでもログイン画面に戻せます。**担当者コードで入り直すと、見積もりは新しいお客様として最初から始まります**（店舗名・担当者名は引き継ぎます）
- **マスタ設定は管理者のみ** — マスタ設定は**担当者コードの画面から開きます**（見積もり画面のタブには出ません）。開くときにパスワードを求めるので、料金や担当者の設定を担当者が勝手に変更できません。**マスタ設定専用のパスワード**を決めれば、店舗のログインパスワードを知らせずにマスタ設定だけを任せられます（決めていない間は店舗ID＋店舗のパスワードで開きます）
- **端末間の同期（任意）** — 設定するとiPadとPCで見積もり・料金マスタが自動で同期します。設定しなくても、その端末の中だけで完結して使えます

## 使い始める

そのまま開けば使えます。設定は不要です。

ホーム画面に追加しておくと、アプリのように起動できます（iPad/iPhoneは共有ボタン →「ホーム画面に追加」、Android/PCはブラウザのインストールボタン）。

## 最初にやっておくとよいこと

1. **料金マスタの確認** — 「料金マスタ」タブを開き、店頭頭金・事務手数料・オプション料金を自店の運用に合わせてください。初期値はドコモ公式の調査値をもとにしています
2. **不要なオプションの削除** — 取り扱いのない商材は削除できます。自店独自の商材は「店舗独自サービス」として追加できます（マスタ設定では「ドコモの商材」と分けて表示されます。見積もり画面の並びは変わりません）
3. **お客様情報の欄** — 見積書に出る店舗名・担当者名を入力しておくと、次回以降も引き継がれます
4. **店舗ログイン**（必要な場合）— マスタ設定の「店舗ログイン」で店舗IDとパスワードを設定すると、アプリを開くたびにログインを求めます。担当者にコードを設定すると、続けて担当者コードの入力になります

**マスタ設定の開き方**: ヘッダーの「担当切替」→ 担当者コードの画面 →「マスタ設定を開く」。担当者コードを1つも設定していない場合は、「担当切替」を押すとそのままマスタ設定が開きます。

## 端末間の同期を使う場合

iPadとPCで同じ見積もりを開きたい場合は、`SETUP.md` の手順でFirebaseの設定をしてください。
設定しない場合でも、アプリはその端末の中だけで完全に動作します。

## 料金について

初期値の料金はドコモ公式サイトの公開情報をもとにしています。実際のご契約時の金額・適用条件とは異なる場合があります。
**最終的な金額は必ず販売店の正規システムでご確認ください。** 本アプリの出力は概算のご案内用です。

料金改定があった場合は「料金マスタ」タブから店舗側で変更できます。

## 動作環境

- Safari / Chrome / Edge の最新版（iPad・iPhone・Android・PC）
- インターネットに繋がらない状態でも、一度開いたあとであれば動作します
