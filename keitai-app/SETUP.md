# 端末間同期（クラウド保存）の設定手順

この設定を行うと、次のことができるようになります。

- iPad ⇄ PC ⇄ スマホ で、見積もりの内容が**自動で同期**される
- 料金マスタ（プラン料金・オプション・手数料）を**全端末で共有**できる
- 担当者A・B・Cの3つの枠を、それぞれ別々に同期できる

**設定しない場合も、アプリはその端末の中だけで完全に動作します。** 1台でしか使わない場合は、この手順は不要です。

所要時間は10分程度です。作業はすべて [Firebaseコンソール](https://console.firebase.google.com/) 上で行います。

> **重要: この同期は「Firebaseプロジェクト1つ＝1店舗」の前提です。**
> ログイン（認証）の仕組みは入っていないため、**同じ設定値を複数の店舗で使い回すと、店舗どうしで見積もりが上書きされます。**
> 店舗ごとに別のFirebaseプロジェクトを作成し、その店舗の `firebase-config.js` にだけ設定値を入れてください。

---

## 1. Firebaseプロジェクトを作成する

1. [Firebaseコンソール](https://console.firebase.google.com/) を開き「プロジェクトを追加」
2. プロジェクト名（例: `keitai-quote-oosaka`）を入力して作成
   - Google アナリティクスは不要（オフでよい）

## 2. ウェブアプリを登録して設定値を控える

1. プロジェクトのトップで、ウェブアイコン（`</>`）をクリック
2. アプリのニックネーム（例: `keitai-app`）を入力して登録
   - 「Firebase Hosting も設定」はチェック不要
3. 表示される `firebaseConfig` の値をコピーする

## 3. 設定値をアプリに貼り付ける

`firebase-config.js` を開き、`KEITAI_FIREBASE` の各項目を手順2の値に差し替えます。

```js
var KEITAI_FIREBASE = {
  apiKey: "AIza...",
  authDomain: "keitai-quote-oosaka.firebaseapp.com",
  projectId: "keitai-quote-oosaka",
  storageBucket: "keitai-quote-oosaka.firebasestorage.app",
  messagingSenderId: "000000000000",
  appId: "1:000000000000:web:xxxxxxxxxxxx"
};
```

`projectId` が入力された時点で同期が有効になり、画面右上に同期の状態が表示されます。
なおこれらの値は、ウェブアプリでは公開される前提のものです。データの保護は手順5で行います。

## 4. データベースを作成する

1. 左メニュー「構築 → Firestore Database」→「データベースの作成」
2. モードは**本番環境モード**、ロケーションは `asia-northeast1`（東京）を選択

## 5. セキュリティルールを設定する

作成後「ルール」タブを開き、内容を同じフォルダの **`firestore.rules`** の中身に置き換えて「公開」します。

## 6. アクセス元のドメインを絞る（推奨）

認証を使わないため、**アプリを置いているドメインからしかアクセスできないように制限**してください。

1. [Google Cloud コンソール](https://console.cloud.google.com/apis/credentials) で同じプロジェクトを開く
2. 「認証情報」→ Firebase が作成したAPIキーを選択
3. 「アプリケーションの制限」で **「ウェブサイト」** を選び、アプリのURL（例: `https://example.com/keitai-app/*`）を追加して保存

## 7. 動作確認

1. アプリを開き、画面右上に同期の状態が出ることを確認
2. ヘッダーの担当者の切り替え（A / B / C）から、この端末の担当を選ぶ
3. 別の端末で同じ担当を選び、片方で入力した内容がもう片方に反映されることを確認

---

## 運用のポイント

| やりたいこと | 操作 |
|---|---|
| 担当者を分ける | ヘッダーの担当切り替えで A / B / C を選ぶ（端末ごとに設定） |
| 同期を止める | 担当切り替えで「同期しない」を選ぶ |
| データを確認する | Firestore Database → `settings/keitaiQuoteA` など |
| 料金マスタを共有する | どの端末で編集しても `settings/keitaiQuoteMaster` 経由で全端末に反映されます |

## データの扱い

- クラウドに保存されるのは、見積もりの入力内容と料金マスタです
- **お客様名を入力した場合はクラウドにも保存されます。** 個人情報を預けたくない場合は、同期を使わないか、お客様名を空欄のまま運用してください
- 通信できない環境でもアプリは動作し、オンラインに戻った時点で同期されます
- 同時に編集した場合は**最後に保存したほうが残ります**（後勝ち）

## 費用の目安

1店舗・数台での利用であれば、Firebaseの無料枠（Spark プラン）に十分収まります。
